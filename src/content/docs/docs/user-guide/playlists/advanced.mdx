:::caution[Power users only!]
Advanced playlists need custom Liquidsoap code. Custom code isn't officially supported by AzuraCast and can stop your station from broadcasting. If something goes wrong, removing your custom code and restarting the station brings it back. Try your changes on a test station first.
:::

:::tip[Try a playlist group first]
Many setups that used to need Liquidsoap code are now possible with [playlist groups](/docs/user-guide/playlists/groups/), without any code. For example, the [ad break example](/docs/user-guide/playlists/group-examples/#ad-break-every-5-songs) shows how to play commercials and bumpers back to back every few songs.
:::

## What an Advanced playlist does

An Advanced playlist is a song-based playlist with the **Playlist Type** **Advanced**. AzuraCast still manages its songs: you add and remove them as usual. But the AutoDJ never plays it by itself. Instead, AzuraCast adds the playlist to the station's Liquidsoap configuration as a source that you can use in your own code.

## Finding a playlist's name in Liquidsoap

Every song-based playlist that's added to the Liquidsoap configuration gets a variable name made from its playlist name:

| Playlist name | Liquidsoap variable |
| --- | --- |
| Commercials | `playlist_commercials` |
| Morning Show | `playlist_morning_show` |
| Night-Show: Part 2 | `playlist_night_show_part_2` |
| Café Música | `playlist_cafe_musica` |
| Rock & Roll | `playlist_rock__roll` |
| Top 40 (2026) | `playlist_top_40_28202629` |
| 1980 | `playlist_playlist_1980` |

If two playlists end up with the same variable name, the second one gets its playlist ID added, for example `playlist_commercials_12`.

As the examples show, special characters can produce unexpected names. To be sure, look up the name on the **Edit Liquidsoap Configuration** page: search for the playlist name and use the variable from the line that looks like `playlist_commercials = playlist(...)`.

[Playlist groups](/docs/user-guide/playlists/groups/) and [Request Queue playlists](/docs/user-guide/song-requests/#request-queue-playlists) are handled entirely by AzuraCast's AutoDJ. They don't have a Liquidsoap variable and can't be used in custom code.

## Adding custom code

Open **Broadcasting › Edit Liquidsoap Configuration** in the station menu. The page shows the station's complete Liquidsoap configuration. The non-editable sections are generated by AzuraCast. The editable text boxes between them are where you add your own code.

The position of your code matters, because it can only use variables that are defined above it. To work with playlist variables, use the first text box **below** the lines that define them.

**Export Configuration** and **Import Configuration** on the same page save and restore your custom code, for example before an update or to copy it to another station.

## Example: playlists back to back

Two playlists, "Commercials" and "Bumpers", should always play right after each other, every few songs.

Create both playlists with the type **Advanced** and add the songs. Then add this line to the first text box below the playlist definitions:

```txt title="Custom code"
radio = rotate(weights=[1, 1, 5], [playlist_commercials, playlist_bumpers, radio])
```

`radio` is defined by AzuraCast and contains everything the station plays at this point. Liquidsoap's `rotate` function takes turns between the sources in the list according to their weights: one track from Commercials, one from Bumpers, then five tracks from the normal programme.

### Fallible sources

Liquidsoap calls a source "fallible" if it might not be able to play something at any moment, for example because a playlist is empty. Playlists are always fallible. Liquidsoap needs an infallible source to fall back on, or it refuses to start.

In the example above, `radio` is the fallback, so nothing else is needed. If you replace the whole output with your own sources, wrap at least one of them with `mksafe` to make it infallible:

```txt title="Custom code"
radio = rotate(weights=[1, 1, 5], [mksafe(playlist_jingles), playlist_commercials, playlist_music])
```

The [Liquidsoap documentation](https://www.liquidsoap.info/) describes all functions and their options. Pick the documentation version that matches the Liquidsoap version of your AzuraCast installation.

## Other playlists in the Liquidsoap configuration

Some playlists are added to the Liquidsoap configuration even if they aren't Advanced:

- **Remote URL playlists**
  - A **Playlist (M3U/PLS) URL** always gets a variable
  - A stream or other remote URL only gets one if the playlist has a schedule, and Liquidsoap switches to it during its scheduled times
  - Without a schedule, there's no variable for it
- **Song-based playlists** with any option on the **Advanced** tab turned on
- **All song-based playlists** if **Always Write Playlists to Liquidsoap** is turned on in the station's AutoDJ settings, or if the station uses [Manual AutoDJ Mode](/docs/user-guide/playlists/autodj-logic/#azuracast-autodj-and-manual-autodj-mode)

You can use their variables in custom code in the same way. Keep in mind that these playlists still play as usual, unless they're Advanced.
